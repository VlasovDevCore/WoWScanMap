# WoW - ScanMap

[Русский](README.ru.md) · [English](../README.md) · **简体中文**

**版本 1.0.1 · Windows x64**

当《魔兽世界》小地图上检测到新的黄色圆点时，程序会显示屏幕提示并播放 Windows 提示音。

[**下载 WoWScanMap.exe**](https://github.com/VlasovDevCore/WoWScanMap/releases/download/v1.0.1/WoWScanMap.exe) · [发行说明与源代码压缩包](https://github.com/VlasovDevCore/WoWScanMap/releases/tag/v1.0.1)

## 快速开始

1. 双击运行 `WoWScanMap.exe`。程序已内置 Python 和所需组件。
2. 以窗口模式打开《魔兽世界》，启用**寻找矿物**或**寻找草药**。
3. 在程序中点击**选择圆形**或**选择正方形**，沿对角线拖动，框住小地图本身，避开边框和按钮。鼠标滚轮调整大小，方向键每次移动一像素。按 **Enter** 或点击**应用**确认，按 **Esc** 取消。
4. 选择与游戏内追踪方式对应的**矿石**或**草药**。点击**开始扫描**，然后返回游戏。
5. 要停止扫描，请返回程序窗口并点击**停止扫描**。

## 设置与工作原理

| 设置 | 作用 |
| --- | --- |
| **Русский / English / 简体中文** | 即时切换界面和提示语言，并记住你的选择。 |
| **圆形 / 正方形** | 设置扫描区域的形状。标准圆形小地图适合使用圆形。 |
| **矿石 / 草药** | 设置提示文字，应与游戏内的追踪方式一致。 |
| **提醒时保存小地图截图** | 将最近一次标记的截图保存为 EXE 或脚本旁的 `last_detection.png`。 |

程序只在游戏窗口位于前台时读取所选屏幕区域的像素。连续检测到黄色小斑点数量增加后，程序发出提示。最近一次检测的预览会用粉色边框标出识别到的斑点。游戏窗口最小化或失去焦点时，扫描暂停。

其他黄色图标可能导致误报。圆形扫描会忽略半径最外侧的 14%，因此靠近边缘的资源可能稍晚才被识别。仅凭圆点颜色无法确定资源名称。各服务器对外部叠加窗口的规定可能不同。[Sirus 规则](https://forum.sirus.org/threads/pravila-igrovyx-mirov-sirus-su.1858/)
