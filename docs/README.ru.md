# WoW - ScanMap

**Русский** · [English](../README.md) · [简体中文](README.zh-CN.md)

**Версия 1.0.1 · Windows x64**

Программа подаёт звуковой сигнал Windows и показывает надпись, когда на миникарте WoW появляется жёлтая точка.

[**Скачать WoWScanMap.exe**](https://github.com/VlasovDevCore/WoWScanMap/releases/download/v1.0.1/WoWScanMap.exe) · [Релиз и архивы исходников](https://github.com/VlasovDevCore/WoWScanMap/releases/tag/v1.0.1)

## Быстрый запуск

1. Открой `WoWScanMap.exe`. Python уже входит в сборку.
2. Открой WoW в оконном режиме и включи **«Поиск минералов»** или **«Поиск трав»**.
3. Нажми **«Выбрать круг»** или **«Выбрать квадрат»** и протяни рамку по диагонали вокруг миникарты без ободка и кнопок. Колесо меняет размер, стрелки сдвигают рамку на пиксель. **Enter** или **«Применить»** подтверждает выбор, **Esc** отменяет.
4. Выбери **«Руда»** или **«Трава»** по активному отслеживанию в WoW. Нажми **«Начать поиск»** и вернись в игру.
5. Для остановки вернись в окно программы и нажми **«Остановить поиск»**.

## Настройки

| Настройка | Что меняет |
| --- | --- |
| **Русский / English / 简体中文** | Сразу меняет язык интерфейса и уведомлений. Выбор запоминается. |
| **Круг / квадрат** | Задаёт форму области. Для стандартной миникарты выбирай круг. |
| **Руда / трава** | Задаёт текст уведомления по выбранному режиму WoW. |
| **Сохранять миникарту при сигнале** | Пишет последний отмеченный кадр в `last_detection.png` рядом с EXE или скриптом. |

Программа проверяет пиксели выбранной области, пока окно WoW активно. Когда число компактных жёлтых пятен устойчиво увеличивается, звучит сигнал. Снимок последнего срабатывания показывает найденные точки в розовых рамках. При свёрнутом или неактивном WoW поиск приостанавливается.

Похожие жёлтые значки могут давать ложные срабатывания. Круглый фильтр пропускает внешние 14% радиуса, поэтому метка у края может определиться позже. Точное название ресурса по цвету точки недоступно. [Правила Sirus](https://forum.sirus.org/threads/pravila-igrovyx-mirov-sirus-su.1858/)
